# Critter Crop

A cozy pixel-art garden game: till and plant crops, attract critters that visit and
move in, summon new ones, brew tonics, and defend the garden from Sludge Critters at
night by flinging your critters at them.

## Play (no internet needed)

1. Download or clone this folder.
2. Open `index.html` in a web browser (Chrome, Edge, Firefox or Safari). No server or
   install is needed.

Progress saves automatically in the browser (localStorage). Each saved garden lives in
that browser on that computer.

## Controls

| Action | Mouse / keyboard | Touch |
| --- | --- | --- |
| Use the selected tool on a tile | Click | Tap |
| Till / plant / water a whole row | Click and drag | Drag |
| Pick a hotbar slot | 1-9, or the scroll wheel | Tap the slot |
| Open the backpack | 0 | Tap the backpack slot |
| Fling a critter (Critterslinging) | Drag back from a critter and let go | Same |
| Critter details | Double-click the critter | Double-tap |
| Move the view | Arrow keys or WASD | -- |
| Pause / resume | P (or the pause button by the clock) | Pause button |

Sound starts after your first click, tap or key press.
